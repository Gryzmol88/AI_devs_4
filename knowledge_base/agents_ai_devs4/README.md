# AI_devs4 Agent Pack

Pakiet plików dla agentów tworzących kod zgodnie z lekcjami AI_devs 4.

## Zawartość
- `01_principles.md` - zasady projektowe i bezpieczeństwa.
- `02_architecture_patterns.md` - wzorce architektury agentowej.
- `03_prompt_templates.md` - szablony instrukcji dla agentów.
- `04_quality_checklist.md` - checklista przed oddaniem zmian.
- `05_task_execution_template.md` - szablon realizacji zadania krok po kroku.

## Szybkie użycie
1. Wczytaj `01_principles.md` jako globalne zasady.
2. Dobierz wzorzec z `02_architecture_patterns.md`.
3. Użyj szablonu z `03_prompt_templates.md`.
4. Realizuj pracę według `05_task_execution_template.md`.
5. Zweryfikuj wynik przez `04_quality_checklist.md`.

## Pliki per lekcja
- Katalog `lessons/` zawiera 1 plik `.agent.md` na każdą lekcję S01-S05.
- Każdy plik zawiera: cel, kluczowe obszary, zasady implementacyjne, checklistę, antywzorce i szablon promptu.
